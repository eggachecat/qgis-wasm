# 插件系统与迁移指南

> English: [03-plugins-and-migration.md](en/03-plugins-and-migration.md)

QGIS 的 wasm 模块里没有 CPython（见 [01-技术方案.md](01-技术方案.md) 的取舍表），所以 PyQGIS 插件不能"原样"运行。本仓库提供三条兼容路径：

| 路径 | 适合 | 怎么做 |
|---|---|---|
| **Python 插件（PyQGIS 兼容层）** | 以 `iface`/`QgsProject`/`QgsVectorLayer`/`processing.run` 为主、UI 只是菜单项 + 简单提示的工具型插件 | 插件代码不改或少改：Python 跑在页面里的 Pyodide 中，`qgis.core` / `qgis.gui` / `qgis.utils` / `qgis.PyQt` / `processing` 由 `web/shell/pyqgis/` 提供，底下通过控制面同步驱动真正的 QGIS（§0） |
| **Web 插件**（JavaScript ES module） | 需要自定义 UI 的插件（HTML 面板）；也是 agent 使用的同一套能力 | 一个 `activate(qgis)` 函数，通过 `qgis.call(tool, params)` 调用 QGIS 的控制面（`QgsWasmBridge`），用 `ui_add_action` 把入口放进真正的 QGIS 菜单/工具栏 |
| **C++ 插件静态编入** | 已有的 QGIS C++ 插件（上游 `src/plugins/*`、企业内部 C++ 插件）、需要 `QgsMapTool`/Qt 面板的插件 | 作为静态库链接进 `qgis.wasm`，入口函数用 `QGIS_PLUGIN_SYMBOL()` 加前缀，登记到 `qgswasmstaticplugins.cpp`；插件管理器照常显示、可启用/禁用 |

## 0. Python 插件

### 0.1 它是怎么跑的

```
preset.plugins_python: ["plugins/hello_pyqgis/"]  或  python_plugins {action:"load", source:"/cloud/shared/plugins/<id>"}
   │  web/shell/pyqgis.js：按需加载 Pyodide（CDN，preset.python.indexUrl 可改），把 web/shell/pyqgis/ 装进 /qgis_shim，
   │  把插件目录复制到 Pyodide 的 /plugins/<id>/（同时镜像到 QGIS 虚拟文件系统 /home/web_user/python-plugins/<id>/，图标/数据可读）
   ▼
qgis.utils.loadPlugin(id); startPlugin(id)  →  classFactory(iface).initGui()
   │  QAction → ui_add_action：条目出现在真正的 QGIS Plugins 菜单 / 插件工具栏；点击 → 事件 → Python triggered 信号
   │  QgsProject / QgsVectorLayer / QgsMapCanvas / processing.run … → qgis._bridge.call(tool) → run_sync(JSPI) → QgsWasmBridge
   ▼
真正的 QGIS（图层、画布、Processing 都是 C++ 的）
```

关键是 Pyodide 的 `run_sync`（基于 JSPI，Chrome ≥ 137）：Python 代码保持同步写法，每个 PyQGIS 调用在底下同步等待一个 bridge Promise。所有进入 Python 的入口（插件加载、菜单回调、信号、`python_run`）都经由 `runPythonAsync` 并串行化，这是 `run_sync` 的前提。

示例：`web/shell/plugins/hello_pyqgis/`（Plugin Builder 风格：`QAction` + `iface.addToolBarIcon/addPluginToMenu`、`QgsVectorLayer(...)` + `QgsProject.instance().addMapLayer()`、`iface.mapCanvas().setExtent()`、`iface.messageBar().pushMessage()`、`QInputDialog.getDouble()`、`processing.run("native:buffer", …)`、`QgsProject.instance().layersAdded.connect()`），默认 preset 已加载。控制台/agent 也能直接跑 Python：

```js
await qgis.call('python_run', { code: "from qgis.core import QgsProject\n[l.name() for l in QgsProject.instance().mapLayers().values()]" })
```

### 0.2 支持范围

兼容层覆盖的是"工具型插件"常用的那部分 API。**下表列出的成员可用；不在表里的名字，`import` 时会报带提示的 `ImportError`**（Qt widget 类则是实例化时抛 `NotImplementedError`，import 本身不报错）。

**`qgis.core`**

- `QgsProject`：`mapLayers` / `mapLayer` / `mapLayersByName` / `addMapLayer(s)` / `removeMapLayer(s)` / `read` / `write` / `fileName` / `title` / `crs` / `setCrs` / `layerTreeRoot`，信号 `layersAdded`、`layersRemoved`、`readProject`、`cleared`。
- `QgsVectorLayer` / `QgsRasterLayer`：`id` / `name` / `isValid` / `extent` / `crs` / `source` / `providerType` / `featureCount` / `fields` / `getFeatures` / `getFeature` / `selectByExpression` / `selectByIds` / `selectAll` / `removeSelection` / `selectedFeatures` / `selectedFeatureCount` / `setOpacity` / `triggerRepaint` / `dataProvider`。
- 要素与字段：`QgsFeature`、`QgsFields`、`QgsField`、`QgsFeatureRequest`（表达式、范围、fid、limit、子集）。
- 几何与坐标：`QgsGeometry`（GeoJSON 为底：`asJson` / `asWkt` / `boundingBox` / `centroid` / `type`）、`QgsRectangle`、`QgsPointXY`、`QgsCoordinateReferenceSystem`（`authid`）、`QgsCoordinateTransform`（经 QGIS 表达式引擎精确变换）。
- 表达式与设置：`QgsExpression`（`evaluate`，可带图层/要素上下文）、`QgsSettings`、`QgsMessageLog`、`QgsApplication.processingRegistry()`、`Qgis.MessageLevel`。

> 要素读取走 `layer_features`（GeoJSON）。大图层请用表达式或 `limit` 收窄，不要整层 `getFeatures()`。

**`qgis.gui`**

- `QgisInterface`：`mapCanvas` / `messageBar` / `mainWindow` / `layerTreeView` / `activeLayer` / `addVectorLayer` / `addRasterLayer` / `addProject` / `newProject` / `zoomFull` / `addPluginToMenu` / `removePluginMenu` / `addToolBarIcon` / `removeToolBarIcon` / `addToolBar` / `addPluginTo*Menu` / `registerMainWindowAction`，信号 `projectRead`、`newProjectCreated`。
- `QgsMapCanvas`：`extent` / `setExtent` / `zoomToFullExtent` / `zoomToSelected` / `zoomIn` / `zoomOut` / `zoomScale` / `setCenter` / `center` / `scale` / `refresh` / `mapSettings` / `layers` / `saveAsImage`，信号 `extentsChanged`、`mapCanvasRefreshed`。
- `QgsMessageBar`：`pushMessage`（两种签名）、`pushInfo` / `pushSuccess` / `pushWarning` / `pushCritical`。

> `QgsMapTool*` 与 `iface.addDockWidget` 抛 `NotImplementedError`——它们需要 C++（见 §2）。

**`qgis.PyQt` / `PyQt5` / `PyQt6`**

- `QtCore`：`QObject`、`pyqtSignal` / `pyqtSlot`、`Qt` 常量、`QTimer`（页面定时器）、`QVariant`、`QCoreApplication.translate`、`QSize` / `QPoint` / `QUrl` / `QFileInfo` 等。
- `QtGui`：`QAction`（成为真正的 QGIS 菜单/工具栏项）、`QIcon`（插件目录内的文件可用）、`QColor`、`QKeySequence`、`QDesktopServices`。
- `QtWidgets`：`QMenu` / `QToolBar`（映射到 Plugins 子菜单/插件工具栏）、`QMessageBox`（浏览器 alert/confirm + 消息栏）、`QInputDialog`（浏览器 prompt）、`QFileDialog`（输入虚拟文件系统路径）、`QProgressDialog`（消息栏）、`QApplication.clipboard()`。

> 其它 widget 类在**实例化时**抛 `NotImplementedError`；`uic.loadUi` / `loadUiType` 不可用——自定义对话框请改成多个菜单项 + prompt，或改用 Web 插件。

**`processing`**

- `run`（图层对象/id/路径作为参数；结果里的图层 id 自动换成图层对象并已加入工程）、`algorithmHelp`、`algorithms`。
- 只有 QGIS 的 C++ `native:*` 算法，没有 Python 算法与模型。

**不支持**

- `QThread` / `QgsTask`：单线程，用 `QTimer` / `asyncio` 分段。
- 编辑会话：`startEditing` / `commitChanges` 返回 False。
- `sqlite3` / `osgeo` / `requests`：Pyodide 自带 `sqlite3`，但打不开 QGIS 文件系统里的文件；网络用 `pyodide.http.pyfetch` 或 bridge 的 `files_download`。
- 自定义 Qt 窗口与地图工具（需要 C++）。

### 0.3 迁移检查清单

1. 对话框：`QDialog`/`.ui` → `QInputDialog.getText/getDouble/getItem`（浏览器原生弹窗，同步）或拆成若干菜单项；复杂 UI → Web 插件。
2. 文件路径：本机路径 → 虚拟文件系统路径（`/cloud/<mount>/…`、`/home/web_user/…`）；`QFileDialog` 变成输入路径。
3. 网络：`requests`/`urllib` → `qgis._bridge.call("files_download", url=...)` 得到本地路径，或 `pyodide.http.pyfetch`。
4. 线程/任务：改为同步小步骤或 `QTimer.singleShot`。
5. 地图工具/面板：`QgsMapTool`、`addDockWidget` → C++ 插件（§2）。
6. 用 `python_run` 在控制台里逐段验证，再放进 `plugins_python`（目录 + `files.json`，或 zip，或放在云挂载目录里：`python_plugins {action:"load", source:"/cloud/shared/plugins/<id>"}`）。


## 1. Web 插件

### 1.1 写法

```js
// web/shell/plugins/my-plugin.js
export default async function activate(qgis) {
  // 菜单：Plugins → My Plugin → Buffer selected layer（相当于 iface.addPluginToMenu）；toolbar: true 再加一个工具栏按钮
  await qgis.call('ui_add_action', { id: 'my.buffer', text: 'Buffer selected layer', menu: 'My Plugin', toolbar: true, icon: 'mActionBuffer.svg' });

  qgis.on('action', async ({ id }) => {                         // 相当于 QAction.triggered
    if (id !== 'my.buffer') return;
    const layers = await qgis.call('layers_list');
    const target = layers.find(l => l.type === 'vector');
    const run = await qgis.call('processing_run', { algorithm: 'native:buffer', parameters: { INPUT: target.id, DISTANCE: 0.5 } });
    await qgis.call('ui_message', { title: 'My Plugin', text: `Buffered ${target.name} → ${run.layers[0].name}`, level: 'success' });
  });

  qgis.on('layers.added', ({ layers }) => console.log('new layers', layers.map(l => l.name)));  // QgsProject.layersAdded
}
```

把文件放到 `web/shell/plugins/`，在 preset 的 `plugins` 列表里登记（`"plugins": ["plugins/my-plugin.js"]`），刷新页面即生效；也可以在控制台里 `import('./plugins/my-plugin.js').then(m => m.default(qgis))` 调试。

### 1.2 可用的 API

- `qgis.call(tool, params) → Promise<result>`：全部工具见 `await qgis.tools()`（当前 68 个，含页面工具与技能工具），分组：`project_*`、`layers_*`、`layer_*`、`canvas_*`、`expression_evaluate`、`processing_*`、`settings_*`、`basemaps_*`、`files_*`、`ui_*`、`plugins_*`、`assistant_*`，以及页面侧的 `project_share`、`mounts_*`、`download`、`file_base64`、`page_info`。每个工具都带 JSON schema（同一份清单也给 MCP 和助手使用）。
- `qgis.on(event, fn)` / `qgis.off`：事件 `ready`、`project.read`、`project.cleared`、`layers.added`、`layers.removed`、`selection.changed`、`canvas.extent`、`canvas.refreshed`、`action`、`assistant.finished`；`'*'` 订阅全部。
- `qgis.open(urlOrPath)`：下载（如果是 URL）后 `layers_add`，不弹对话框；`window.qgisOpen()` 则走 `QgisApp::openFile()`（带 QGIS 自己的子图层对话框）。
- `qgis.share(path)`：生成 `?preset=…&open=<path>` 链接；`qgis.mount(cfg)` / `qgis.mounts()`：云存储挂载；`qgis.instance.FS`：Emscripten 文件系统（`readFile`/`writeFile`）。

### 1.3 PyQGIS → Web 插件对照

| PyQGIS | Web 插件 |
|---|---|
| `classFactory(iface)` / `initGui()` | `export default async function activate(qgis)` |
| `iface.addPluginToMenu(name, action)`、`iface.addToolBarIcon(action)` | `ui_add_action { id, text, menu, toolbar, icon }` |
| `action.triggered.connect(fn)` | `qgis.on('action', ({ id }) => …)` |
| `iface.removePluginMenu(...)` / `unload()` | `ui_remove_action { id }` |
| `iface.messageBar().pushMessage(title, text, level)` | `ui_message { title, text, level, duration }` |
| `QgsProject.instance().mapLayers()` / `mapLayersByName()` | `layers_list`（结果里有 id、name、type、provider、source、crs、extent、fields、featureCount） |
| `QgsVectorLayer(uri, name, provider)` + `addMapLayer()` | `layers_add { uri, name, provider }`（文件、URL、`{z}/{x}/{y}` 瓦片模板、任何 QGIS data source URI） |
| `QgsRasterLayer(uri, name, 'wms')` (XYZ) | `layers_add { uri: 'https://…/{z}/{x}/{y}.png' }` 或 `basemaps_use { name }` |
| `QgsProject.instance().removeMapLayer(id)` | `layers_remove { layer }` |
| `QgsProject.instance().read(path)` / `write(path)` | `project_open { path }` / `project_save { path }`（`/cloud/<mount>/…` 即保存到对象存储） |
| `QgsProject.instance().setCrs(crs)` | `project_set_crs { crs }` |
| `layer.getFeatures(QgsFeatureRequest().setFilterExpression(e).setLimit(n))` | `layer_features { layer, expression, limit, geometry, fields }` → GeoJSON FeatureCollection |
| `layer.selectByExpression(e)` / `iface.mapCanvas().zoomToSelected()` | `layer_select { layer, expression, behavior, zoom }` |
| `layer.fields()` | `layer_fields { layer }` |
| `layer.setRenderer(QgsSingleSymbolRenderer(symbol))`、`setOpacity()` | `layer_set_style { layer, fill, stroke, stroke_width, size, opacity, label_field, label_size, label_color, label_buffer, label_bold, label_placement }`（快捷；只改给出的键，现有符号是起点） |
| `setRenderer(QgsCategorizedSymbolRenderer / QgsGraduatedSymbolRenderer)`、色带、`setLabeling(QgsVectorLayerSimpleLabeling(settings))`、`QgsTextFormat`（字体/描边/背景/位置/比例尺范围）、`setMinimumScale()` | `layer_style_set { layer, renderer: {type: single \| categorized \| graduated, symbol, field, categories, ranges, classes, mode, ramp}, labels: {field \| expression, size, color, font, bold, buffer, background, placement, offset, overlap, min_scale, max_scale, …}, opacity, min_scale, max_scale }`；`layer_style_get { layer }` 读回同一份 JSON 文档。Python 里 `QgsPalLayerSettings`、`QgsTextFormat`、`QgsTextBufferSettings`、`QgsVectorLayerSimpleLabeling`、`QgsSymbol/QgsMarkerSymbol/QgsLineSymbol/QgsFillSymbol`、`QgsSingleSymbolRenderer`、`QgsCategorizedSymbolRenderer + QgsRendererCategory`、`QgsGraduatedSymbolRenderer + QgsRendererRange`（含 `createRenderer()`、`setClassificationMethod()`）、`QgsGradientColorRamp`、`QgsStyle.defaultStyle().colorRamp(name)` 都是这份文档的 PyQGIS 外衣：对象是脱离的副本，`layer.setRenderer()` / `setLabeling()` 时才发给 QGIS（和 PyQGIS 语义一致）；`layer.renderer()` / `labeling()` 每次从 QGIS 读回。不在子集里的名字（`QgsRuleBasedRenderer`、`QgsSvgMarkerSymbolLayer`…）`import` 时报带提示的 `ImportError`，提示用 QML 或 bridge 工具 |
| `layer.loadNamedStyle(path)` / `saveNamedStyle(path)` / `importNamedStyle(doc)` / `exportNamedStyle()` | `layer_style_qml { layer, qml?, path?, save? }`：完整的 QGIS QML（规则渲染、SVG 符号、栅格着色……图层属性对话框能做的都能装进去） |
| `layer.setName()`、`setScaleBasedVisibility()`、图层树勾选 | `layer_set_properties { layer, name, visible, opacity, min_scale, max_scale }` |
| `iface.mapCanvas().extent()` / `setExtent()` / `zoomToFullExtent()` / `refresh()` | `canvas_extent` / `canvas_set_extent { xmin, ymin, xmax, ymax, crs }` / `canvas_zoom_full` / `canvas_refresh` |
| `iface.mapCanvas().saveAsImage(path)` | `canvas_export_image { path, width, height }` + `file_base64 { path }` 取字节 |
| `QgsExpression(e).evaluate(context)` | `expression_evaluate { expression, layer }` |
| `processing.run('native:buffer', params)` | `processing_run { algorithm, parameters, add_to_project }`：图层型输出（sink / vectorDestination / rasterDestination）留空 = 临时图层并加入工程；文件型输出（`fileDestination` / `folderDestination`，如 `native:savefeatures` 的 `OUTPUT: '/cloud/…/x.gpkg'`、`native:package`）就是一条路径，留空时给临时文件，结果在 `results.OUTPUT`，再用 `layers_add` 打开；`processing_list { filter }`、`processing_describe { algorithm }` 查算法与参数（只有 C++ 的 `native:*`，没有 Python 算法） |
| `QgsSettings().value(k)` / `setValue(k, v)` | `settings_get { key }` / `settings_set { key, value }` |
| `QgsProject.instance().layersAdded.connect(fn)` 等信号 | `qgis.on('layers.added' \| 'layers.removed' \| 'project.read' \| 'selection.changed' \| 'canvas.extent', fn)` |
| `QFileDialog`、自定义 Qt 对话框 | 用 HTML/JS 做（页面层），或把参数设计成 `ui_add_action` 的几个固定菜单项；需要真正 Qt 对话框的功能走 C++ 插件 |
| `iface.addDockWidget(...)` 自定义面板 | 暂无 Web 等价物（Qt 面板只能来自 C++）；轻量面板可以做成页面上的 HTML 浮层 |
| 读写本地文件 `open(path)` | `files_list / files_read_text / files_write_text / files_download`，或 `qgis.instance.FS` |
| `urllib` / `requests` 访问内部服务 | 直接 `fetch()`（受 CORS 约束；无 CORS 的服务可经 `scripts/serve.mjs` 的 `/proxy?url=`） |

没有对应物、也不打算有的：`QgsMapTool` 子类（自定义鼠标工具）、Qt 自定义对话框/面板、Python Processing 算法与模型（`model3` 中只含 native 算法的模型可以通过 `processing_run` 逐步调用）。这些需要走 C++ 路径。

### 1.4 迁移步骤

1. 列出插件的入口（菜单/工具栏项）→ 每个变成一个 `ui_add_action`。
2. 把 `initGui()` 里的逻辑移到 `activate()`；把每个 `triggered` 处理函数翻译成 `qgis.on('action')` 分支。
3. PyQGIS 调用按上表替换；凡是需要"读很多要素"的地方用 `layer_features` 的 `expression`/`fields`/`limit` 收窄，或者改用 `processing_run`/`expression_evaluate`（`aggregate()` 等）在 QGIS 内部计算。
4. 对话框：参数少 → 多个菜单项或 `window.prompt`；参数多 → 一个 HTML 面板。
5. 用 `tests/e2e/drive.py`（`js:` 步骤）或 Playwright 写回归。

## 2. C++ 插件静态编入

上游的 **Topology Checker**（`src/plugins/topology`）和 **Geometry Checker**（`src/plugins/geometry_checker`）已经以这种方式编进 `qgis.wasm`：Plugins → Manage and Install Plugins 里能看到并启用它们，Topology Checker 启用后在 Vector 菜单和面板中出现。

### 2.1 机制

- 浏览器里没有 `dlopen()`。`src/plugins/CMakeLists.txt` 在 Emscripten 下把插件目标编成 `STATIC` 库，`cmake/QgisWasmApp.cmake` 的 `QGIS_WASM_STATIC_PLUGINS` 把它们链接进可执行文件。
- 插件的 C 入口（`classFactory`、`name`、`description`、`category`、`type`、`version`、`icon`、`unload`）在一个可执行文件里会互相冲突，所以每个插件编译时定义 `QGIS_PLUGIN_STATIC_NAME=<库名>`，源码里用 `qgisplugin.h` 的 `QGIS_PLUGIN_SYMBOL()` 声明入口：

  ```cpp
  QGISEXTERN QgisPlugin *QGIS_PLUGIN_SYMBOL( classFactory )( QgisInterface *iface ) { return new MyPlugin( iface ); }
  QGISEXTERN const QString *QGIS_PLUGIN_SYMBOL( name )() { return &sName; }
  // description / category / type / version / icon / unload 同理
  ```

  动态库构建下这个宏什么也不做，所以同一份源码仍可编成普通的 `.so`。
- `src/app/qgswasmstaticplugins.cpp` 用一张表登记这些入口；`QgsPluginRegistry`（加载/卸载/恢复会话）和 `QgsPluginManager`（列表）在 Emscripten 下查这张表而不是扫描目录。插件的 `.qrc` 资源在表初始化时 `Q_INIT_RESOURCE`。

### 2.2 接入自己的 C++ 插件

1. 把插件源码放进 `external/QGIS/src/plugins/<name>/`（或用 `CUSTOM_PLUGINS`），`add_library(plugin_<name> ${QGIS_PLUGIN_LIBRARY_TYPE} …)`，Emscripten 下 `target_compile_definitions(plugin_<name> PRIVATE QGIS_PLUGIN_STATIC_NAME=plugin_<name>)`。
2. 入口函数改用 `QGIS_PLUGIN_SYMBOL()`（8 处）。
3. `qgswasmstaticplugins.cpp`：加 `QGIS_WASM_DECLARE_PLUGIN( plugin_<name> )`、表项 `QGIS_WASM_PLUGIN_ENTRY( plugin_<name> )`，以及 `Q_INIT_RESOURCE( <qrc 名> )`；`QgisWasmApp.cmake` 的 `QGIS_WASM_STATIC_PLUGINS` 加上目标名。
4. 不可用的依赖（Python、串口、PostgreSQL、QtWebEngine…）要么去掉，要么用 `__EMSCRIPTEN__` 守卫。
5. 在 preset 的 `plugins_cpp` 里写上库名，用户第一次打开就处于启用状态。

### 2.3 从 Python 插件到 C++ 插件

需要 `QgsMapTool`、自定义 Qt 对话框/面板的插件，建议用 C++ 重写 UI 层（`QgisInterface` 的 API 与 PyQGIS 一一对应：`iface->addPluginToMenu`、`iface->mapCanvas()`、`QgsProject::instance()` …），业务逻辑如果主要是表达式/Processing 调用，也可以拆成 C++ 外壳 + Web 插件两部分。

## 3. 用 agent 替代一部分插件

很多"小插件"只是把几步 QGIS 操作串起来。页面上的 Web Agent（`web/agent`，docs/05；以及通过 MCP 接进来的外部 agent）拿到的是和 Web 插件完全相同的工具集，所以"给我把 X 图层按 Y 字段标注并导出图片"这类任务可以不写插件直接让 agent 做；需要固化的流程再沉淀成 Web 插件。见 [04-云存储-Preset-Agent.md](04-云存储-Preset-Agent.md)。
